# Next.js Frontend (Retro UI)

UI-first scaffold for:
- Header with navigation (Search / Meal Planner / Admin)
- Responsive recipe grid/list area (grid implemented; list toggle placeholder)
- Meal planner calendar placeholder
- Favorites + Shopping List drawer/sidebar (responsive: drawer on small screens, sidebar on large screens)

## Run
```bash
npm install
npm run dev
```

The root route `/` redirects to `/app`.
